# 룰 구현 범위와 한계

이 문서는 사용자가 제공한 `루미큐브 룰북.pdf`의 4개 페이지를 기준으로
현재 자동 판정기가 구현하는 규칙을 정리합니다.

## 구현된 규칙

- 그룹: 같은 숫자이면서 색이 서로 다른 타일 3개 또는 4개
- 연속: 같은 색의 연속된 숫자 3개 이상
- 숫자 1은 가장 낮은 숫자이며 13 다음에 이어지지 않음
- 턴 종료 시 테이블의 모든 타일이 유효한 세트에 속해야 함
- 기존 테이블 타일이 턴 후 사라지면 위반
- 정상 턴에는 최소 한 개의 새 타일이 추가되어야 함
- 최초 등록 전에는 기존 테이블 타일을 이동하거나 조합할 수 없음
- 최초 등록 타일 합계는 30점 이상이어야 함
- 조커는 그룹 또는 연속에서 부족한 타일을 대신할 수 있음

## 이미지 기반 판정 방식

1. YOLO26n이 각 타일의 클래스와 바운딩 박스를 검출합니다.
2. 타일 높이를 기준으로 같은 행의 타일을 묶습니다.
3. 같은 행에서 큰 수평 간격이 보이면 서로 다른 세트로 분리합니다.
4. 각 세트에 그룹 또는 연속 규칙을 적용합니다.
5. 이전 턴과 현재 턴의 클래스별 타일 수를 비교합니다.
6. 위반이면 이전 정상 이미지와 상태를 유지하고, 정상이면 현재 이미지를
   다음 턴의 기준으로 확정합니다.

## 자동화가 완전하지 않은 부분

- 카메라가 움직이면 기존 타일 이동 판정이 부정확해질 수 있습니다.
- 손이나 랙에 가려진 타일은 테이블에서 사라진 것으로 오판할 수 있습니다.
- 동일한 클래스의 타일이 두 개이므로 위치 대응에는 모호성이 있습니다.
- 세트 사이 간격이 좁으면 두 세트를 하나로 묶을 수 있습니다.
- 조커를 회수할 때 사용해야 하는 정확한 대체 타일과, 회수한 조커를 같은
  턴에 다시 사용했는지는 두 장의 정지 영상만으로 완전히 증명하기 어렵습니다.
- 플레이어가 랙에서 실제로 어떤 타일을 냈는지는 테이블 카메라만으로 직접
  볼 수 없습니다. 최초 등록 여부는 플레이어별 외부 상태로 관리해야 합니다.
- 턴 제한 시간과 Pool에서 가져온 타일 수는 영상 외의 게임 상태가 필요합니다.

따라서 현재 버전은 고정된 상단 카메라와 사람이 확인 가능한 상세 판정
결과를 사용하는 보조 시스템입니다. 정확도를 높이려면 손이 완전히 빠진 후
촬영하고, 테이블 모서리 마커를 이용한 원근 정렬과 플레이어별 상태 관리가
추가로 필요합니다.
